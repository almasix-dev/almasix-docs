# Almasix docs

Official application-developer documentation for [Almasix](https://github.com/almasix-dev/almasix),
built with [Astro Starlight](https://starlight.astro.build/).

Published at **[docs.almasix.com](https://docs.almasix.com/)**. See [`CLOUDFLARE.md`](./CLOUDFLARE.md).

Contributor contracts (`PLAN.md`, `SMOKE.md`) stay in the
[`almasix`](https://github.com/almasix-dev/almasix) repo under `docs/`.

## Develop

```bash
npm ci
npm run dev
```
